# 标签分类整理 MVP（Chrome 扩展）

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目目录：`d:\谷歌插件coding`

## 使用

1. 在普通窗口中点击标签栏右侧“+”新建标签
2. 会直接进入“标签分类”页面
3. 仅“浏览器顶部手动新建标签页”会触发分类页；网页内链接新开标签（如文档跳转）不会触发
4. 页面中可执行：
   - 自动按域名查看分类结果
   - 拖拽标签到其他分类
   - 新建自定义分类（仅名称）
   - 删除空的自定义分类
   - 关闭标签 / 单独打开标签
5. 点击“完成整理”后，按当前分类顺序重排标签并关闭整理页
6. 点击“取消”会退出整理页并打开空白新标签页

## 说明

- 基于 Manifest V3
- 权限使用 `tabs`、`storage`、`sessions`、`webNavigation`
- 仅适配 Chrome 普通窗口场景
